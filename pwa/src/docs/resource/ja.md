# Resources 使用說明

## 概述

**Resources** は外部参照リソースライブラリであり、発見した有用なウェブサイト、チュートリアル、参考資料などを保存・管理するためのものです。

## 主な機能

### リソースの追加

**+ Add** ボタンをクリックして新しいリソース項目を作成します。システムは自動的に Resource ID（`R` で始まる）を生成します。

### リソースの編集

デスクトップ版では、表の行をクリックして編集します。モバイル版では、カードをクリックして編集ダイアログを開きます。

### リソースの検索

- 検索ボックスにキーワードを入力します
- **Title、Category、Note、URL** に基づいて全文検索を行うことができます
- 2つの検索モードをサポートしています：
  - **OR モード**（デフォルト）：任意のキーワードに一致する項目を表示します（例："React Vue" を検索すると "React" **または** "Vue" を含む項目が表示されます）
  - **AND モード**：すべてのキーワードに一致する項目を表示します（例："React Tutorial" を検索すると "React" **かつ** "Tutorial" を含む項目が表示されます）

### リソースの削除

表の右側にある **Delete** ボタンをクリックして行項目を削除します。

## フィールドの説明

| フィールド | 説明 |
|------|------|
| **Resource ID** | システムが自動生成、`R` で始まる（非表示） |
| **Title** | リソース名 |
| **Category** | カテゴリタグ（例：Tutorial、Reference、Tool） |
| **Received** | リソース追加日時 |
| **Note** | 備考欄 |
| **URL** | 外部リンク、「開く」ボタンをクリックして直接開くことができます |

## ベストプラクティス

- 各リソースに明確な **Title** と **Category** を付けて、後で検索しやすくします
- **URL** フィールドは外部リソースへの直接ナビゲーションをサポートしています
- **Note** フィールドを使用して追加情報を提供します。例えば、なぜこのリソースを保存したのかなどです
- 検索機能を活用して、必要なリソースを素早く見つけます

## ヒント

- モバイル版ではカード形式で表示され、デスクトップ版では表形式で表示されます
- 検索はリアルタイムで行われ、Enter キーを押す必要はありません
