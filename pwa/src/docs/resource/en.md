# Resources Usage

## Overview

**Resources** is an external reference resource library used to save and manage useful URLs, tutorials, reference materials, etc. that you discover.

## Main Features

### Add Resource

Click the **+ Add** button to create a new resource item. The system will automatically generate a Resource ID (prefixed with `R`).

### Edit Resource

In the desktop version, click the table row to edit; in the mobile version, click the card to open the edit dialog.

### Search Resource

- Enter keywords in the search box
- Full-text search can be performed based on **Title, Category, Note, URL**
- Supports two search modes:
  - **OR mode** (default): matches any keyword (e.g., searching for "React Vue" will show items containing "React" **or** "Vue")
  - **AND mode**: must match all keywords (e.g., searching for "React Tutorial" will show items containing both "React" **and** "Tutorial")

### Delete Resource

Click the **Delete** button on the right side of the table to delete the row item.

## Field Description

| Field | Description |
|------|------|
| **Resource ID** | Automatically generated by the system, prefixed with `R` (hidden) |
| **Title** | Resource name |
| **Category** | Category tag (e.g., Tutorial, Reference, Tool) |
| **Received** | Resource added time |
| **Note** | Note field |
| **URL** | External link, can be opened directly by clicking the "Open" button |

## Best Practices

- Give each resource a clear **Title** and **Category** for easy subsequent search
- The **URL** field supports direct navigation to external resources
- Use the **Note** field to provide additional information, such as why this resource is saved
- Make good use of the search function to quickly find the required resources

## Tips

- The mobile version will be displayed in card form, while the desktop version uses a table form
- The search is performed in real-time, no need to press the Enter key
