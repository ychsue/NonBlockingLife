# Candidates

## 目的

1. 現在できるすべてのことを重要性に基づいて順序付けし、リスト化して、ユーザーがその中から何を行うか選択できるようにする。
2. 脳を単一スレッドの実行スレッドとして扱うため、一度に一つのタスクしか実行できません。一度タスクを開始すると、完了するまで画面はそのタスクにロックされ、選択可能な状態に戻るのは完了後です。
3. 中断が許可されており、API または ⚡ ボタンを押すことで現在のタスクを中断し、その後中断されたタスクに改善することができます。
4. 中断と中断されたタスクは任意の種類のタスクであり、⚡ ボタンを押すことで現在のタスクを中断し、どの中断タスクに入るかを選択できます。
5. 中断タスク自体がタスクであるため、タスクが実行中であってもなくても、いつでも中断することができます。終了時に、なぜ中断したのか、何をしたのかを記録し、`Log` に保存します。
6. 中断ボタンを通じて、いつでも特定の状態やタスクに入るためのポータルとしても機能します。もしその状態やタスクが存在しない場合、システムは自動的に作成し、対応するタスクカテゴリに保存して、後で再利用や分析ができるようにします。
7. 現在のタスクの状態は画面に表示され、ユーザーは自分が何をしているのかを把握できます。
8. したがって、これは最も頻繁に使用されるページです。

## 使用方式

1. 任務を選択する：
    1. タスクをクリックすると、ダイアログボックスが表示され、このタスクを開始する理由を記録します。確認後、タスクが実行されます。
    2. 一度確認すると、画面はこのタスクを実行するダイアログボックスに留まり、右上隅に実行時間が表示されます。ユーザーが `タスク終了` をクリックするまで、このタスクは終了せず、開始理由と実行内容が `Log` に記録されます。
    3. タスクを中断するには、⚡ ボタンをクリックします。これにより現在のタスクが終了し、中断タスクのダイアログボックスに移行します。これらの操作はすべて `Log` に記録されます。
2. 🔄 候補を更新する：
    1. `候補を更新` ボタンをクリックすると、データベースからタスクを再読み込みし、優先度順に表示されます。
    2. 原則として、このページに戻るたびに自動的に更新されます。
3. クイックアセスメント：
   1. 上にある項目ほど注意を払うべきです。
   2. 赤は期限切れ、緑は今日ほぼ十分であることを示します。
   3. `Task Pool` のタスクに `⛔` が付いている場合、それはそのタスクにあまり時間をかけたくないことを意味します（例えば、ソーシャルメディア）。使用しすぎると、灰色になり取り消し線が引かれ、使用しすぎであることを知らせます。
   4. 各項目には残り時間が表示されており、実行するかどうかの判断がしやすくなっています。
4. 締め切り（Deadline）：
   1. `Task Pool`、`Micro Tasks`、`Scheduled` の各タスクで締め切り（Deadline）を設定できます。
   2. 締め切りが近いほどスコアが高くなり、タスクは上位に表示されます：7日以内はカウントダウンバッジ、3日以内はオレンジ色、当日はオレンジ色で強調、期限切れは赤で表示されます。
   3. 期限切れの加点には上限（+500）があるため、タスクが長期間期限切れであっても、システムはすぐに処理することを強制しません——これはユーザーの判断です。定期的に確認し、これらの期限切れタスクを続行するか、延期するか、破棄するかを決定することをお勧めします。
   4. `Scheduled` タスクの次回実行時間（Next Run）が締め切りより後の場合、候補ページの上部に警告エリアが表示されます。項目をクリックすると、直接 `Scheduled` 編集ページに移動してスケジュールや締め切りを修正できます。
5. iPhone でのショートカットの使用：
   1. `NBL Query` ショートカットをインストールすると、このページが開きます（注意：iPhone のショートカットは PWA を開くことができないため、ほとんどの場合、新しい Safari ウィンドウでこのページが表示されます。これは避けられません）。これにより、現在どのタスクが実行可能かをすばやく確認し、何を行うかを選択できます。
      1. iPhone の `コントロールセンター` に配置することをお勧めします。これにより、iPhone の右上隅から下にスワイプして、このショートカットをすばやく選択し、このページを開くことができます。
      2. iPhone の `ロック画面` の `ウィジェット` に配置することをお勧めします。これにより、ロック画面から直接現在実行可能なタスクを確認できます。
   2. `NBL Interrupt` ショートカットをインストールすると、現在のタスクをすばやく中断できるようになります。これにより、見逃すことがありません。
      1. iPhone の `コントロールセンター` に配置することをお勧めします。これにより、iPhone の右上隅から下にスワイプして、このショートカットをすばやく選択し、現在のタスクを中断できます。
      2. iPhone の `ロック画面` の `ウィジェット` に配置することをお勧めします。これにより、ロック画面から直接現在のタスクをすばやく中断できます。
   3. `NBL_Timer` ショートカットをインストールすると、`Apple Clock` のタイマー機能と連携して、ポモドーロ・テクニックを利用し、作業すべきか休憩すべきかを通知してくれます。
6. Android アプリの使用：
   * ウィジェットをホーム画面に直接追加すると、現在どのタスクが実行可能かをすばやく確認できます。
7. いつでも中断を使用する：
   1. いつでも特定のタスクを実行したり、特定の状態に入ったりする場合は、中断を通じて行うことができます。これにより、見逃すことがありません。
   2. 中断されたタスクがある場合、黄色で表示され、リストの上部に固定されます。これにより、どのタスクがまだ完了していないかを一目で確認できます。
   3. この中断が、例えば突然の緊急事態のようなもので、記録したいが名前を思いつかない場合は、再度 ⚡ をクリックすると、中断タスクのダイアログボックスが表示されます。
   4. この中断をタスクや状態に変えたい場合は、🔍 をクリックし、名前を入力すると、システムがそれを見つけます。存在しない場合は、新しいタスクや状態が作成されます。
   5. したがって、中断はいつでも使用可能です。
