# Inbox

## 目的

インスピレーションを素早く記録し、後で時間を見つけて分類する

## 使用方法

1. 追加：
   1. `+Add` をクリックすると新しい項目を追加できます。
   2. iPhone では、`ショートカット` の `NBL Inbox` を `設定➡️アクセシビリティ➡️タッチ➡️背面タップ➡️ダブルタップ` にバインドできます。これにより、iPhone の背面をダブルタップするだけで、新しいアイデアを自動的に追加できます。
   3. iPhone の任意のウェブページで、`NBL Inbox` をインストールした後、その URL を NonBlockingLife の Inbox に共有することもできます。
   4. Android では、`NBL Inbox` のウィジェットをホーム画面に追加して、素早くアイデアを記録できます。
   5. YouTube、Chrome などの `共有` 機能を使って、内容を NonBlockingLife の Inbox に共有することもできます。
2. 削除：
   1. 各レコードには `Delete` ボタンがあり、またはモバイルで左にスワイプして削除することもできます。
   2. 毎日時間を見つけて分類し、分類後に削除します。
      1. 些細なことは、終わったらすぐに削除します。
      2. 締め切りなどの時間的な制約がない小さなタスクは、タイトルをコピーして `Micro Tasks` に追加します。
      3. 時間に関連するタスクは、`Scheduled` に追加します。
      4. 1 日以上かかるタスクは、`Task Pool` に追加します。
      5. 参考資料は、`OneNote` や `Notion` など、普段使用している外部記録リソースに保存してください。
3. 編集：
    1. モバイルでは、項目を右にスワイプして編集画面に入り、変更後に `保存` を押します。
    2. コンピュータでは、変更が完了すると、フォーカスが入力フィールドを離れた時点で更新されます。
