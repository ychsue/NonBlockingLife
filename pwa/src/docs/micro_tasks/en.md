# Micro Tasks

## Purpose

Tasks that can be handled in short bursts of time. Once completed, they are marked as Done and will no longer appear in `Candidates`.

## How to Use

1. Adding:
   1. Click `+Add` to create a new task.
   2. Since at most one task is added per day, there is no corresponding iPhone `Shortcut`.
2. Deleting: (Not recommended. It is better to mark as Done to keep statistical data.)
   1. Each record has a `Delete` button, or you can swipe left on your phone.
   2. Another advantage of only setting the status to Done is that you can quickly find and execute it again in `Candidates` if needed.
3. Editing:
    1. On mobile, swipe right on the item to enter the edit screen, and press `Save` after making changes.
    2. On a computer, changes are updated immediately once focus is lost.
4. Starting and Ending:
   1. Select a task from `Candidates` to start. Ending is also done in `Candidates`, and it will then be recorded in the `Log`.
