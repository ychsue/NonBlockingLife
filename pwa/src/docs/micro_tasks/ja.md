# Micro Tasks

## 目的

ちょっとした隙間時間で処理する小さなタスクは、処理が完了したら「Done」に設定し、`Candidates` に表示されないようにします

## 使用方式

1. 追加：
   1. `+Add` をクリックして新しいタスクを追加します。
   2. 1日に追加できるタスクは最大1件なので、対応するiPhoneの `ショートカット` はありません。
2. 削除：（削除は推奨されません。統計データを保持するために Done に設定する方が良いです。）
   1. 各レコードには `Delete` ボタンがあり、またはスマートフォンで左にスワイプして削除できます。
   2. ステータスを Done に設定するもう一つの利点は、後で `Candidates` 内で再度実行したい場合に、すぐに見つけて実行できることです。
3. 編集：
    1. モバイルの場合、項目を右にスワイプして編集画面に入り、変更後に `保存` を押します。
    2. コンピュータの場合、フォーカスが外れた時点で変更が即座に更新されます。
4. 開始と終了：
   1. `Candidates` からタスクを選択して開始します。終了も `Candidates` 内で行い、その後 `Log` に記録されます。
