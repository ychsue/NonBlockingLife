# Task Pool

## 目的

1. 時間がより多くかかる作業、例えばプロジェクトなどをここに置くことで、ユーザーがそれらを確認でき、実行するかどうかを決定できるようにします。
2. `Daily Limit` を設定すると、ユーザーはこれらのタスクに毎日どれだけの時間を費やすかを指定できます。この制限を超えた場合、
   1. 通常は緑色になり、その日のタスクがうまく実行されたことを示します。
   2. `Title` に `⛔` が含まれている場合、これは実際にはあまり時間をかけたくないタスク（例えばソーシャルメディア）であることを示します。したがって、使用しすぎると、灰色に打ち消し線が付き、使用しすぎであることを知らせます。

## 使用方式

1. 追加：
   1. `+Add` をクリックして新しいタスクを追加します。
2. 削除：（削除は推奨されません。統計データを保持するために、Done にマークすることをお勧めします。）
   1. 各レコードには `Delete` ボタンがあり、またはモバイルでは左にスワイプして削除できます。
3. 編集：
    1. モバイルでは、項目を右にスワイプして編集画面に入り、変更後に `保存` を押します。
    2. コンピュータでは、変更が完了すると、フォーカスが入力フィールドを離れた時点で更新されます。
