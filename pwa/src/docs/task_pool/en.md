# Task Pool

## Purpose

1. Putting those tasks that require more time, such as projects, here allows users to have a place to see them and decide whether to do them.
2. Setting a `Daily Limit` allows users to specify how much time they want to spend on these tasks each day. When this limit is exceeded:
   1. Under normal circumstances, it will turn green, indicating that the task has been well-executed today.
   2. If the `Title` contains `⛔`, it indicates that this task is something you actually do not want to spend much time on (e.g., social media). Therefore, if you use it too much, it will turn gray with a strikethrough, indicating that you have overused it.

## Usage

1. Adding:
   1. Click `+Add` to add a new task.
2. Deleting: (Not recommended. It is suggested to mark it as Done instead, so that statistical data is preserved.)
   1. Each record has a `Delete` button, or you can swipe left on mobile.
3. Editing:
    1. On mobile, swipe right on the item to enter the edit screen, and press `Save` after making changes.
    2. On a computer, changes are updated as soon as the focus leaves the input field.
